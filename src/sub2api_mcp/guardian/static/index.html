调度说明

Guardian 每轮如何从样本得到状态与候选调度参数。

  1. 01
    同步与采样

    读取渠道、账号与真实流量，补充到期主动探测。

  2. 02
    分类与评分

    区分成功、慢响应、网关、限额、探测失败和致命错误。

  3. 03
    状态决策

    依次应用人工控制、分组保底、熔断、降级和健康回池。

  4. 04
    权重候选

    按价格、速度或均衡策略归一化分组预算。

  5. 05
    安全输出

    观察模式只记录期望动作；授权后仍需租约、冷却和幂等审计。
